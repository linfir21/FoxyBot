# FoxBot 🦊

Telegram-бот «Лисёночек» — милый лис-ассистент, который шлёт лисичек, отвечает на любые сообщения через ИИ и раздаёт приложение со скрытым чатом.

## Особенности

- **Фото лис** — случайные фотографии через API [randomfox.ca](https://randomfox.ca/), с автоматическим fallback на котов (TheCatAPI), если основной API недоступен
- **ИИ-чат** — «Лисёночек» отвечает на любые сообщения через Kimi (Moonshot AI), помнит контекст диалога и имеет свой характер
- **Раздача APK** — команда `/app` отправляет игру 2048 со скрытым E2E-чатом (Eraze), рядом кнопка создания комнаты через Django-бэкенд
- **Нежные кнопки** — комплименты, обнимашки и фырканье в один тап
- **Рассылка** — админская команда `/broadcast` с подтверждением по inline-кнопке (список хранится в SQLite-БД `users.db`, переживает перезапуски)
- **Статистика** — админская команда `/stats`: пользователи и сообщения за сегодня
- **Факты о лисах** — команда `/foxfact` генерирует короткий факт через ИИ (без истории, дёшево)
- **Авто-забывание** — ИИ-история протухает после 12 часов неактивности (настраивается через `AI_HISTORY_TTL_HOURS`)
- **Логирование** с ротацией (`foxbot.log`, до 50 МБ × 5 копий)

## Команды

| Команда      | Описание                                                        |
|--------------|-----------------------------------------------------------------|
| `/start`     | Приветствие, клавиатура и первая случайная фотография           |
| `/newfox`    | Отправить новое случайное фото лисы                             |
| `/app`, `/game` | Отправить APK игры 2048 + кнопку создания комнаты чата       |
| `/forget`    | Сбросить историю диалога с ИИ                                   |
| `/foxfact`   | Случайный факт о лисах от ИИ                                    |
| `/stats`     | Статистика (только админ): пользователи, сообщения за сегодня   |
| `/broadcast` | Рассылка с подтверждением (только админ, формат: `/broadcast текст`) |

## Установка и запуск

1. Создайте файл `.env` в корне проекта:
   ```
   TOKEN=ваш_токен_от_BotFather          # обязательно
   MOONSHOT_API_KEY=ключ_kimi            # для ИИ-чата (необязательно)
   ADMIN_ID=ваш_telegram_id              # для /broadcast (узнать: @userinfobot)
   APK_PATH=2048.apk                     # путь к файлу игры (по умолчанию 2048.apk)
   DJANGO_API_URL=http://127.0.0.1:8000/api  # бэкенд для создания комнат
   BOT_API_TOKEN=токен_бэкенда           # заголовок X-Bot-Token, должен совпадать с сервером
   AI_HISTORY_TTL_HOURS=12               # через сколько часов бот забывает диалог (по умолчанию 12)
   WEBHOOK_URL=https://ваш-домен:8443/foxbot  # если задан — webhook вместо polling
   WEBHOOK_PORT=8443                     # порт для webhook-сервера
   ```

   По умолчанию бот работает через polling — `WEBHOOK_URL` можно не задавать.

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите бота:
   ```bash
   python foxbot.py
   ```

## Как это работает

- **Лисы:** основной API возвращает ссылку на фото; при ошибке бот пробует TheCatAPI и честно шлёт кота
- **ИИ-чат:** системный промпт задаёт лисью личность; история диалога обрезается до 10 последних сообщений, чтобы контролировать стоимость API
- **Комнаты чата:** бот стучится в Django-эндпоинт `/api/room/create/` с токеном `X-Bot-Token` и присылает пользователю код комнаты
- **Обновление APK:** файл читается при каждом запросе — достаточно заменить `2048.apk` на сервере, и все получат новую версию

## Структура проекта

```
foxbot/
├── foxbot.py         # Основной файл бота (вся логика в одном месте)
├── tests/
│   └── test_foxbot.py # Тесты на чистую логику (без сети и Telegram)
├── requirements.txt  # Зависимости
├── .env              # Секреты (токены, не коммитится)
├── users.db          # База chat_id для рассылки, SQLite (создаётся автоматически)
├── foxbot.log        # Логи с ротацией (создаётся автоматически)
└── README.md         # Описание проекта
```

При первом запуске старый `users.json` автоматически мигрирует в `users.db`
(исходник сохраняется как `users.json.bak`).

## Логирование

Логи сохраняются в файл `foxbot.log`. При достижении размера 50 МБ файл автоматически архивируется (сохраняется до 5 резервных копий).

## Тесты

```bash
venv/Scripts/python.exe -m pytest tests/ -v
```

Покрыто: хранение пользователей и миграция из users.json, статистика, получение
фото лис (включая fallback на котов), обрезка и TTL ИИ-истории, изоляция
одноразовых ИИ-запросов, рассылка с подтверждением (включая защиту от чужих
подтверждений).

## Требования

- Python 3.11+
- Токен бота от [@BotFather](https://t.me/BotFather)
