# FoxBot 🦊

«Лисёночек» — Telegram-бот с характером настоящей лисы: хитрый, игривый и нежный. Он фыркает на комплименты, обнимается в ответ на обнимашки, шлёт случайные фотографии лис и поддерживает живой разговор на любую тему через ИИ — помнит контекст диалога, рассказывает факты о своих сородичах и никогда не забывает о своих людях. А если разговор остановится, просто забудет его через 12 часов и начнёт всё с чистого листа, как и положено дикому зверю.

## Особенности

- **Фото лис** — случайные фотографии через API [randomfox.ca](https://randomfox.ca/), с автоматическим fallback на котов (TheCatAPI), если основной API недоступен
- **Лиса дня** — каждый день в 6:30 (настраивается `DAILY_FOX_HOUR`/`DAILY_FOX_MINUTE`) бот сам шлёт всем пользователям фото лисы + нежную фразу и лисий факт. Без подписок и команд: достаточно один раз написать боту
- **ИИ-чат** — «Лисёночек» отвечает на любые сообщения через Kimi (Moonshot AI), помнит контекст диалога (история хранится в SQLite и переживает рестарт) и имеет свой характер
- **Понимает картинки** — пришли фото, и бот обсудит его (vision у kimi-k2.6; подпись к фото = вопрос о картинке)
- **Понимает голосовые** — распознаёт речь (нужны `SpeechRecognition` и ffmpeg) и отвечает в общем диалоге
- **Погода по геопозиции** — кнопка «🌤 Погода» присылает геопозицию, бот отвечает текущей погодой и прогнозом на день (Open-Meteo, без ключа)
- **Игры** — кнопка «🎮 Игры» открывает меню из трёх игр: «Угадай число» (1–100), «Хвостик-Мордашка-Лапка» (лисьи «камень-ножницы-бумага»: хвост бьёт морду, морда кусает лапу, лапа бьёт хвост) и «Правда или ложь» (5 фактов про лис, не повторяются, пока не пройдёшь все). Выход — «Хватит играть» или `/stopgame`
- **Игры APK** — кнопка «🎮 Игры APK» отправляет описание игр (2048 со скрытым чатом и «Азбука для малышей») и ссылку на скачивание с Яндекс.Диска. Отдельная раздача APK и создание комнат чата убраны — всё через ссылку
- **/translate и /summary** — перевод и короткий пересказ текста (или реплаем на сообщение)
- **/mood** — настроение лисёнка: `playful` (игривый), `romantic` (нежный), `calm` (спокойный), `grumpy` (ворчливый старый лис). Подмешивает суффикс к системному промпту, выбор хранится в SQLite и меняется на лету без потери диалога
- **Rate limiting** — не больше 10 ИИ-запросов в минуту на чат (`AI_RATE_LIMIT`/`AI_RATE_WINDOW_SECONDS` в `.env`), спамер не разгонит счёт за API; админ без лимита
- **Обратная связь** — `/feedback текст` пересылает сообщение админу, админ отвечает реплаем — бот доставляет ответ пользователю
- **Нежные кнопки** — «Фыр ❤️» (15 фраз: комплименты, обнимашки и фырканье) и «Горяченькое 🔥» в один тап. Лисёночек — девушка-лиса: нежная, игривая и слегка кокетливая, все тексты бота в её стиле
- **Рассылка** — админская команда `/broadcast` с подтверждением: текстом или реплаем на фото/видео/документ (копия уходит всем). Заблокировавшие бота пользователи автоматически удаляются из базы
- **Статистика** — админская команда `/stats`: пользователи, активные сегодня, сообщения за сегодня и за 7 дней, топ часов активности
- **Игра 2048 + чат** — команда `/app` отдаёт APK со скрытым зашифрованным чатом и кнопкой создания комнаты
- **Факты о лисах** — команда `/foxfact` генерирует короткий факт через ИИ (без истории, дёшево)
- **Меню команд** — регистрируется через `set_my_commands` при старте, Telegram сам показывает его пользователям
- **Авто-забывание** — ИИ-история протухает после 12 часов неактивности (настраивается через `AI_HISTORY_TTL_HOURS`)
- **Логирование** с ротацией (`foxbot.log`, до 50 МБ × 5 копий)

## Команды

| Команда      | Описание                                                        |
|--------------|-----------------------------------------------------------------|
| `/start`     | Приветствие, клавиатура и первая случайная фотография           |
| `/newfox`    | Отправить новое случайное фото лисы                             |
| `/forget`    | Сбросить историю диалога с ИИ                                   |
| `/foxfact`   | Случайный факт о лисах от ИИ                                    |
| `/translate` | Перевести текст (или ответь командой на сообщение)              |
| `/summary`   | Короткий пересказ текста (или ответь командой на сообщение)     |
| `/feedback`  | Написать админу (он ответит реплаем)                            |
| `/mood`      | Настроение лисёнка: playful / romantic / calm / grumpy          |
| `/stopgame`  | Закончить игру «Угадай число»                                   |
| `/stats`     | Статистика (только админ)                                       |
| `/broadcast` | Рассылка с подтверждением (только админ): текст или реплаем на любое сообщение |
| `/updatekb`  | Обновить клавиатуру у всех (только админ)                       |
| `/games` (`/abc`) | Описание игр APK и ссылка на скачивание        |

## Установка и запуск

1. Создайте файл `.env` в корне проекта:
   ```
   TOKEN=ваш_токен_от_BotFather          # обязательно
   MOONSHOT_API_KEY=ключ_kimi            # для ИИ-чата и vision (необязательно)
   ADMIN_ID=ваш_telegram_id              # для /broadcast и /feedback (узнать: @userinfobot)
   AI_HISTORY_TTL_HOURS=12               # через сколько часов бот забывает диалог (по умолчанию 12)
   DAILY_FOX_HOUR=6                      # час ежедневной «лисы дня» (по времени сервера)
   DAILY_FOX_MINUTE=30                   # минута ежедневной «лисы дня»
   AI_RATE_LIMIT=10                      # максимум ИИ-запросов от одного чата...
   AI_RATE_WINDOW_SECONDS=60             # ...за столько секунд (защита от спама)
   DOWNLOAD_URL=https://...              # ссылка для APK больше 50 МБ
   WEBHOOK_URL=https://ваш-домен:8443/foxbot  # если задан — webhook вместо polling
   WEBHOOK_PORT=8443                     # порт для webhook-сервера
   ```

   По умолчанию бот работает через polling — `WEBHOOK_URL` можно не задавать.

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

   Для голосовых сообщений дополнительно нужен **ffmpeg** в PATH
   (конвертация OGG → WAV перед распознаванием). Без него бот работает,
   но на голосовые отвечает «не расслышал».

3. Запустите бота:
   ```bash
   python foxbot.py
   ```

## Приложения

- **Игры APK:** бот не хранит и не шлёт файлы — кнопка «🎮 Игры APK» и команда `/games` отправляют описание игр и ссылку `DOWNLOAD_URL` (Яндекс.Диск). APK больше лимита Telegram в 50 МБ

- **Лисы:** основной API возвращает ссылку на фото; при ошибке бот пробует TheCatAPI и честно шлёт кота
- **ИИ-чат:** системный промпт задаёт лисью личность; история диалога обрезается до 10 последних сообщений, чтобы контролировать стоимость API, и хранится в SQLite — рестарт бота её не стирает
- **Vision:** фото от пользователя уходит в kimi-k2.6 в base64; картинка тарифицируется фиксированно (~1024 токена) и в историю диалога не попадает

## Структура проекта

```
foxbot/
├── foxbot.py         # Точка входа: фасад (re-export для тестов) + main()
├── config.py         # .env, константы, промпты, настроения (/mood)
├── core.py           # Логирование и общий экземпляр TeleBot
├── content.py        # Тексты: фразы кнопок, приветствия, подписи, коды погоды
├── storage.py        # SQLite (пользователи, статистика, истории) + состояние в памяти
├── kimi.py           # Запросы к ИИ и rate limiting
├── keyboards.py      # Все клавиатуры (reply + inline)
├── handlers/         # Обработчики по темам
│   ├── fox.py        # /start, лисы, «лиса дня», /foxfact, /forget
│   ├── chat.py       # Текст, голосовые, фото, /translate, /summary, /mood
│   ├── apps.py       # «Игры APK»: описание игр и ссылка
│   ├── fun.py        # Погода по геопозиции, игры («🎮 Игры»: число, хвостик-мордашка-лапка, правда-ложь)
│   └── admin.py      # /stats, /broadcast, /updatekb, /feedback
├── tests/
│   └── test_foxbot.py # Тесты на чистую логику (без сети и Telegram)
├── requirements.txt  # Зависимости
├── .env              # Секреты (токены, не коммитится)
├── users.db          # SQLite: пользователи, статистика, ИИ-истории, мета (создаётся автоматически)
├── foxbot.log        # Логи с ротацией (создаётся автоматически)
└── README.md         # Описание проекта
```

Модули читают настройки через `config.X` в момент использования, общие
словари состояния (истории, игры, рассылки) живут в `storage.py` — тесты
подменяют их через фасад `foxbot.X`.

При первом запуске старый `users.json` автоматически мигрирует в `users.db`
(исходник сохраняется как `users.json.bak`).

## Логирование

Логи сохраняются в файл `foxbot.log`. При достижении размера 50 МБ файл автоматически архивируется (сохраняется до 5 резервных копий).

## Тесты

```bash
venv/Scripts/python.exe -m pytest tests/ -v
```

Покрыто: хранение пользователей и миграция из users.json, расширенная статистика,
служебные ключи meta, получение фото лис (включая fallback на котов), обрезка и
TTL ИИ-истории, персистентность истории в SQLite (переживает рестарт, стирается
/forget), изоляция одноразовых ИИ-запросов, рассылка с подтверждением (текст и
копия любого сообщения реплаем, защита от чужих подтверждений), мини-игра
«Угадай число».

## Требования

- Python 3.11+
- Токен бота от [@BotFather](https://t.me/BotFather)
- (опционально) ffmpeg — для голосовых сообщений
